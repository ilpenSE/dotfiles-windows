# DotFiles for Windows

- It's isolated from user profile name but you have to install Git Bash for git
- Then clone this repo in home folder by: `git clone https://github.com/ilpenSE/dotfiles-windows.git`
- You can run `setup.bat` for all the settings.

# Requirements

- Windows 11
- Git Bash: GNU bash, version 5.2.37(1)-release (x86_64-pc-msys)
- Visual Studio 2026 Build Tools with MSVC, Windows SDK
- C/C++ MSVC for x64 Version 19.50.35723
